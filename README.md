# Сайт студии nail.lounge

Минск, пр-т Независимости, 11/2 · метро «Площадь Ленина», 290 метров · ежедневно 09:00–21:00.

Ветка `claude/beauty-salon-website-minsk-aimxdf` — это только сайт студии.
Соседний проект репозитория (салон «Пафия») живёт на своей ветке
`claude/pafiya-barbershop-site-2vlg9t` и сюда не попадает.

Статический сайт без зависимостей. Собирается одной командой, на выходе —
обычные HTML-файлы, которые кладутся на любой хостинг, GitHub Pages, Netlify
или в папку на сервере. Node 18+, `npm install` не нужен: внешних пакетов нет.

```bash
npm run build    # собрать сайт
npm run edit     # редактор в браузере — правки без кода
npm run check    # проверить: микроразметку, ссылки, заголовки, размеры кнопок
npm run draft    # собрать черновик для показа: плашка и запрет индексации
npm run phone    # открыть сайт на телефоне из домашней сети
npm run photos   # список мест под фотографии с размерами
npm run serve    # локальный просмотр на http://localhost:8080
```

## Редактор

**Двойной клик по `START-EDITOR-MAC.command`** (macOS) или
**`START-EDITOR-WINDOWS.bat`** (Windows) — терминал не нужен. Откроется браузер
с админкой: формы, кнопки «выше/ниже/дублировать/удалить», кнопка «Сохранить».

После сохранения данные пишутся в `src/data/*.json`, сайт сразу пересобирается,
рядом в журнале появляются найденные проблемы. Откат — через git, поэтому перед
большой правкой удобно закоммитить текущее состояние.

Редактор слушает только `127.0.0.1` и в интернет не смотрит.

| Раздел редактора | Что внутри | Файл данных |
|---|---|---|
| Студия и контакты | Адрес, телефон, мессенджеры, график, рейтинг, реквизиты, меню | `src/data/site.json` |
| Цены | Все позиции с ценой и длительностью, «что входит», «из чего складывается сумма» | `src/data/prices.json` |
| Услуги | Три страницы направлений: шаги визита, вопросы-ответы, выделенные блоки | `src/data/services.json` |
| Мастера | Карточки, тексты, подписи к работам, история студии | `src/data/masters.json` |
| Тексты страниц | Первый экран, стерильность, атмосфера, галерея, отзывы, сертификаты | `src/data/content.json` |

Одна правка расходится по всему сайту сразу: цена попадает и в таблицу, и в
список услуг в форме записи, и в микроразметку для поиска.

## Запись

Кнопка «Записаться» есть на каждой странице, а на телефоне ещё и в липкой
панели внизу — в зоне большого пальца. Нажатие открывает окно с двумя путями:

1. **Мессенджер или звонок** — Telegram, Viber, WhatsApp, Instagram, телефон.
   Работает сразу и ничего не требует от студии.
2. **Форма** — имя, телефон, услуга, мастер, день и время. Заявка собирается
   в готовое сообщение, которое отправляется в мессенджер одной кнопкой
   или копируется целиком.

Так запись работает на статике, без сервера и без бота.

**Когда появится бот или система записи.** Впишите адрес обработчика в
редакторе: «Студия и контакты» → «Приём заявок» → «Адрес обработчика»
(или `site.booking.endpoint` в `src/data/site.json`). Форма начнёт отправлять
туда JSON методом POST:

```json
{ "name": "Ирина", "phone": "+375 29 123-45-67", "service": "Маникюр с покрытием",
  "master": "Карина", "date": "2026-09-15", "time": "Вечер, 16:00–21:00", "comment": "" }
```

Если сеть подведёт, форма не потеряет заявку — предложит отправить её
в мессенджер. Если студия заведёт YCLIENTS или DIKIDI, их виджет встраивается
на место формы; поля `systemName` и `systemUrl` в данных для этого и оставлены.

## Фотографии

Настоящих снимков студии у нас нет, а брать чужие из 2ГИС и инстаграма нельзя —
права у авторов. Поэтому на их местах аккуратные заглушки в палитре сайта.

**Как заменить.** Посмотрите список имён и размеров:

```bash
npm run photos
```

Положите снимок в `assets/img/` с тем же именем и расширением `.webp`, `.jpg`
или `.png` — например `hero-studio.webp` вместо `hero-studio.svg` — и соберите
сайт заново. Заглушка сама уступит место фотографии, вёрстка не сдвинется:
размеры уже прописаны в разметке.

Снимки лучше сжать в WebP и не грузить оригиналы с телефона: страница должна
открываться быстро на мобильном интернете.

## Что заменить перед запуском

Сайт собран на данных из открытых источников и на правдоподобных заготовках.
Что-то надо подтвердить, что-то — заменить. По убыванию важности:

| Что | Где | Почему это важно |
|---|---|---|
| **Цены и длительность** | Редактор → «Цены» | Сейчас это ориентиры по рынку Минска. Ради прозрачных цен сайт и делается |
| **Фотографии студии и работ** | `assets/img/` | Стоковые руки с идеальным маникюром аудитория считывает мгновенно |
| **Отзывы** | Редактор → «Тексты страниц» → «Отзывы» | Сейчас заготовки по мотивам настоящих. Нужны реальные цитаты с Google и firmi.by |
| **Стерильность** | Редактор → «Тексты страниц» → «Стерильность» | Режимы сухожара и марки оборудования надо узнать у владельцев: заявление без конкретики вызывает недоверие |
| **Состав команды** | Редактор → «Мастера» | Список собран по упоминаниям в отзывах 2021–2025. Имя мастера по бровям неизвестно |
| **Реквизиты юрлица** | Редактор → «Студия и контакты» → «Реквизиты» | Наименование, УНП, юридический адрес, регистрирующий орган. Без них подвал и юридические страницы неполные |
| **Ссылки на мессенджеры** | Редактор → «Мессенджеры» | Telegram и WhatsApp проставлены по номеру телефона — надо проверить, что они рабочие |
| **Координаты на карте** | Редактор → «Координаты для карт» | Сейчас приблизительные: нужны точные, иначе карты уведут не туда |
| **Домен** | Редактор → «Адрес сайта» | Пока стоит `naillounge.by`. От него зависят canonical, карта сайта и превью в мессенджерах |
| **Счётчики** | Редактор → «Аналитика» | Метрика и Google Analytics подключаются только после согласия на cookie |

Оферту и политику обработки данных перед публикацией стоит показать юристу:
это рабочая заготовка под законодательство РБ, а не готовый документ.

Отдельная задача вне сайта: **заявить карточку в Google Business Profile**.
Сейчас она не подтверждена владельцем, и без этого сайт будет получать меньше
трафика с карт. Делается бесплатно и за полчаса.

## Дизайн

Светлая лавандовая база, один акцент, много воздуха — интерфейс не спорит
с фотографиями работ.

- **Палитра.** Бумага `#fcfafd`, чернила `#241f2a`, акцент — приглушённая
  лаванда `#7a6494`, для наведения и ссылок — `#5f4c77` и `#5a4670`,
  подложка `#f1ecf6`, поддержка — шалфей `#5c6e61`. Все цвета живут
  в переменных в начале `assets/css/style.css`: поменяли пять строк —
  поменялся весь сайт, включая значки, логотип и превью для мессенджеров.
- **Контраст проверен по WCAG.** Текст к фону — не ниже 4,5:1, контуры
  полей, кнопок и фильтров — не ниже 3:1. Если будете менять цвета,
  держите эти пороги: на них держится читаемость на телефоне при солнце.
- **Шрифты.** Заголовки — Lora, интерфейс — Manrope. Больше двух семейств нет.
- **Мобильная версия основная.** Всё, что вне медиазапросов, — про телефон.
  Десктоп добавляется сверху.
- **Тач-таргеты** не меньше 44×44 пикселей, это проверяется автоматически.
- **Движение** уважает `prefers-reduced-motion`.
- Иконки — контурные SVG в одном стиле. Эмодзи не используем: они выглядят
  по-разному в разных системах и не читаются скринридером.

Слово «прайс» на сайте не встречается — только «цены». Это проверяет
`npm run check` и ругается, если оно вернётся.

## SEO и аналитика

Уже сделано:

- Микроразметка `BeautySalon` с адресом, часами, телефоном и координатами;
  `Service` на каждой странице услуги; `OfferCatalog` с ценами; `FAQPage`
  для вопросов-ответов; `Person` для мастеров; хлебные крошки.
- Open Graph и превью для мессенджеров — трафик пойдёт из инстаграма
  и Telegram, там картинка решает.
- `sitemap.xml`, `robots.txt`, canonical на https, отдельные заголовки
  и описания под каждый запрос.
- Cookie-баннер с возможностью отказа: счётчики загружаются только после
  согласия — так требует законодательство РБ.

Счётчики включаются в редакторе, в разделе «Аналитика». Пока поля пустые,
никакие сторонние скрипты на сайт не подгружаются.

## Публикация

Сайт статический — подойдёт любой хостинг. Файлы для выкладки: все `*.html`,
папки `assets`, `masters`, `legal`, а также `robots.txt`, `sitemap.xml`,
`site.webmanifest`, `.nojekyll`. Папки `src` и `tools` нужны только для сборки
и в интернет не выкладываются.

Для показа заказчику удобнее черновик:

```bash
npm run draft
```

Он добавляет плашку «Черновик сайта» и закрывает страницы от поисковиков,
чтобы макет с придуманными ценами не нашли по запросу «nail lounge минск»
и не приняли за настоящий сайт студии.

В репозитории лежит сценарий `.github/workflows/pages.yml` — публикация
черновика на GitHub Pages. Он запускается **вручную** (вкладка Actions →
«Публикация черновика nail.lounge» → Run workflow): в соседней ветке
репозитория живёт другой проект со своей публикацией, а адрес GitHub Pages
у репозитория один — автозапуск перетирал бы чужой выложенный черновик.
