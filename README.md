# Сайт салона-парикмахерской «Пафия»

Минск, ул. Притыцкого, 73, офис 144 · метро «Кунцевщина» · с 2011 года.

Статический сайт без зависимостей. Собирается одной командой, результат —
обычные HTML-файлы, которые кладутся на любой хостинг, GitHub Pages, Netlify
или в папку на сервере.

```bash
npm run build         # собрать сайт в корень репозитория
npm run check         # проверить: JSON-LD, метатеги, битые ссылки и якоря
npm run serve         # собрать и поднять локально на http://localhost:8080
npm run build:single  # плюс однофайловая версия для показа, см. ниже
npm run edit          # редактор в браузере, см. ниже
```

Node 18+. Внешних пакетов нет — `npm install` не нужен.

### Однофайловая версия для показа

`npm run build:single` дополнительно собирает `dist/pafia-sayt.html` —
весь сайт в одном файле: стили, скрипт и все картинки внутри, переходы между
страницами на хеш-роутере (`#/prices`, `#/masters/larisa`). Открывается двойным
кликом без сервера, весит около 0,5 МБ — можно отправить клиенту в мессенджере
или показать с флешки, когда хостинга ещё нет.

Это версия исключительно для демонстрации. В интернет выкладывается обычная
многофайловая: у неё нормальные адреса страниц, отдельные title и description,
canonical и sitemap — то есть всё, за счёт чего страницы попадают в поиск.

## Редактор

Двойной клик по файлу в корне проекта — `START-EDITOR-WINDOWS.bat`
или `START-EDITOR-MAC.command`. Откроется окно с журналом, браузер
с редактором запустится сам. Терминал при этом не нужен.

Имена латиницей и батник целиком в ASCII с переносами CRLF — не из любви
к аскетизму: кириллица внутри .bat ломает разбор в cmd.exe, а переносы
в стиле Unix обрывают выполнение. `.gitattributes` помечает `*.bat`
бинарным, чтобы git не переписал переносы обратно.

Из командной строки то же самое:

```bash
npm run edit          # http://127.0.0.1:4321
```

Единственное требование — установленный Node.js 18 или новее
(nodejs.org, кнопка LTS). Больше ничего ставить не надо: у проекта нет
зависимостей, `npm install` не нужен.

Локальная админка: правите цены, мастеров, тексты и контакты в формах,
нажимаете «Сохранить и пересобрать» — данные пишутся в `src/data/*.json`,
сайт пересобирается, кнопка «Открыть сайт» показывает результат.

Что удобно знать:

- Телефон достаточно ввести в любом виде — ссылка `tel:` подставится сама.
- У списков есть стрелки, дублирование и удаление: карточку мастера или
  раздел с ценами проще скопировать, чем набирать заново.
- «Отменить правки» возвращает к последнему сохранению. Более глубокий
  откат — через git, поэтому перед крупной правкой удобно закоммититься.
- Сервер слушает только `127.0.0.1` и наружу не смотрит. Авторизации у него
  нет — это инструмент для разработчика на своей машине, а не админка,
  которую можно выставить в интернет.

Если цены должен менять администратор салона, поверх этих же JSON-файлов
кладётся git-based CMS вроде Decap: формат данных для этого уже подходящий.

### Откуда что берётся

Весь контент лежит в `src/data/` — правится там, не в HTML:

- `site.json` — NAP: адрес, телефоны, часы, реквизиты. Меняется в одном месте, обновляется везде, включая подвал и микроразметку.
- `prices.json` — цены и топ-10 для главной.
- `masters.json` — мастера (включая падежные формы имени: «записаться к Ларисе», «работы Ларисы»).
- `techniques.json` — страницы техник окрашивания.
- `content.json` — блоки услуг, галерея, FAQ, «Вход в салон», текст «О салоне».

Рядом лежат одноимённые `.mjs` — тонкие обёртки: подгружают JSON и считают
производные значения. Данные правятся в JSON, логика живёт в `.mjs`.
Добавили в данные новое поле — допишите строку в схему в `tools/editor-ui.html`,
и оно появится в редакторе.

`src/lib/` — шаблон страницы, компоненты, иконки, генератор фото-заглушек,
минимальный PNG-кодировщик для og-превью. `src/pages/` — сборка конкретных страниц.

## Подключение записи и аналитики

Форма записи работает в демо-режиме: валидирует поля, показывает
подтверждение и пишет заявку в консоль браузера. Чтобы заявки доходили,
добавьте перед `main.js` на всех страницах (проще всего — в `src/lib/layout.mjs`):

```html
<script>
  window.PAFIA_CONFIG = {
    bookingEndpoint: 'https://…',  // Telegram-бот, YClients, DIKIDI или свой обработчик
    metrikaId: 12345678            // Яндекс.Метрика; без него аналитика не грузится
  };
</script>
```

Форма отправляет JSON: `name`, `phone` (нормализован в `+375XXXXXXXXX`),
`service`, `master`, `date`, `time`, `comment`, `page`.

Цели для Метрики уже расставлены: `booking_sent`, `phone_click`, `viber_click`.
Метрика подключается **только после согласия** в cookie-баннере, карта Яндекса —
только по клику на кнопку «Показать карту».

Единственный сторонний запрос, который уходит со страницы до согласия, —
шрифт Manrope с Google Fonts. Если нужна полная чистота по 99-З, скачайте
две-три нужные насыщенности в `assets/fonts/` и замените `<link>` на
локальный `@font-face`: сайт станет ещё и быстрее. Системный фолбэк уже
прописан, так что до замены ничего не сломается.

## Технические решения

- **Мобайл-фёрст.** Нижняя панель «Позвонить · Viber · Записаться» на экранах уже 940px, крупные цели нажатия, кликабельные `tel:` и `viber://`.
- **Скорость.** Ни одного JS-фреймворка, один CSS-файл, одна внешняя гарнитура. Картинки ленивые, размеры проставлены. Метрика и карта — по согласию и по клику.
- **Доступность.** Семантическая разметка, ссылка «Перейти к содержанию», видимый фокус, `aria-expanded` на меню, `prefers-reduced-motion`, контраст текста выше 4.5:1.
- **SEO.** У каждой страницы свой title и description, canonical, Open Graph. Микроразметка: `HairSalon` c рейтингом и часами работы, `BreadcrumbList`, `FAQPage`, `OfferCatalog` со всеми ценами, `Person` для мастеров, `Service` для техник окрашивания.
- **Одна гарнитура** (Manrope) с системным фолбэком: сайт остаётся читаемым, даже если внешние шрифты не загрузились.
